# Visual workspaces

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users and task

Merchants design their shop and developers create apps in Veyndo Studio. The user
approved a shared zoomable overview of real shop pages and app placements, followed
by direct editing with a large preview, collapsible tools and a contextual agent
on the right. Element actions expose ordering, duplication, deletion and app behavior.

## Existing constraints

Retain Veyndo's existing Studio identity, blue branding and translated controls.
Use the current shop renderer and app definition. Manual edits, AI and coding-agent
proposals keep their native permission, revision, sandbox and publication paths.
References are untrusted evidence. Preview never executes commerce changes.
Storyfront retains its original editor. The shared canvas owns presentation only.

## Success

Move between overview and editing without losing a draft; compare a proposal before
adopting it; use keyboard, pointer or touch for equivalent element operations.
