# Guided setup in Veyndo Studio

This is a feature extension of the existing merchant Studio, not a separate
product or visual identity. It inherits Studio typography, semantic surface and
accent tokens, native fields, navigation, roles and responsive controls.

New shop owners need a clear first step, a useful result at each stage, and a way
back after ordinary work. The welcome is optional. The guide covers company
details, products, design, checkout, legal information and a deliberate test.
The sidebar entry reopens the saved step. Active setup keeps a visible return
path from native live shop views. Small screens keep the current step in view.

Company details save through the native settings owner. All other tasks open
their existing owners. AI help uses the current merchant setup area and the same
proposal, approval and sandbox paths as the rest of Studio. No automatic provider
setup or publication is introduced.

Progress is personal to the current account and live shop. It shares the existing
workspace revision, history and row security, preserves unrelated layout edits,
and rejects a concurrent setup edit before replacing progress. A completed area
means the user reviewed it. It does not certify provider readiness, legal
compliance or a completed purchase. Existing data never silently completes a step.

Success is a usable first company save, clear native destinations, explicit
review progression, pause/reopen without loss, current-context AI, and the same
usable path at desktop and mobile widths.
