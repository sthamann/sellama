# Personal workspace

Private actor/tenant arrangements use `/api/studio/workspace` and native MCP
`studio.workspace.read/save`. Presets suggest cards; they never grant access.
Current shell admission filters every card and linked view. Layout versions retain
20 personal revisions; they are operational preferences and excluded from shop
clones/releases. Goals refer to the existing assistant/proposal and Flow owners.
No second agent scheduler, commerce store or authorization model lives here.

`workspace-presentation.ts` admits the entity, criteria and current rights
before projecting the workspace with the pinned SDK. A2UI v1.0 arranges
the native directory, permitted intake and shipping policy controls.
OpenUI provides the fallback. Both paths mount the same local bindings.
External hosts can use the same SDK contract with their own scoped clients.
