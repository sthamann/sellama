# Shared visual canvas

Presentation-only zoom, pan and bounded scene navigation for Shop design and App
Studio. Domain adapters supply the existing renderers, scenes and open callbacks.
No records, credentials, definition copies or business actions are stored here.

Edit actions appear above scene previews. The toolbar view picker opens the same
native callback without shrinking with the zoomed board, including disabled access.
The shared primary button styles override broad workspace button resets.
